02　現状課題文言確認用

毎回、誰かがゼロから作っている。

日常の広報物ほど、外注しづらく、職員の時間を静かに奪います。

01
担当者ごとに見た目が変わる

引き継ぐたびに、品質がリセットされる。

02
修正指示が感覚的になる

「もう少し見やすく」が何度も往復する。

03
外注するほどではないが、時間がかかる

イベント告知や説明資料が後回しになる。

04
AIで作ってもそのまま出せない

組織のルール、正確性、確認工程が足りない。

制作時間の問題に見えて、実際は「判断が人の頭の中にしかない」ことが根本です。
03　ツールだけでは足りない

AIやテンプレートを入れるだけでは、解決しません。

道具は増えました。けれど「この組織なら、どう見せるか」が共有されていません。

TOOLS

PowerPoint / Canva / 生成AI

便利な道具

MISSING

組織の判断基準

何を良しとするか / 何を避けるか / 誰が確認するか

OUTPUT

ばらつく / 確認が必要

必要なのは、新しいツールではなく、既存のルール・素材・確認を「使える仕組み」にすること。
04　目指す状態

目指すのは、同じ見た目ではなく、同じ組織に見えること。

ルールは守りながら、用途に応じて表情を変えます。画一化ではなく、判断してよい幅を設計します。

公式・明快

制度・事業を正確に伝える

親しみ・参加促進

参加したくなる入口をつくる

先進・知的

研究・未来を知的に見せる

固定する：ロゴ / 色 / 表記 / 必須情報 / 確認　｜　変化させる：写真 / 構成 / 余白 / 強弱 / トーン
05　解決策

組織の「これなら出してよい」を、職員とAIが使える仕組みにする。

単発のプロンプトではなく、次の資料にも使い回せる「組織の制作基盤」が残ります。

01 集める

過去資料 / ブランドガイド / 承認済み素材

02 ルールにする

見た目・表記 / 構成・禁止事項 / 用途別判断

03 つくる

AIで構成・文章 / テンプレートへ反映

04 確かめる

チェックリスト / 責任者確認 / 改善履歴

AIでデザインを自動化するのではなく、制作判断を組織の仕組みに変えます。
06　利用者体験

職員が答えるのは、デザインの専門知識ではありません。

利用者が持っている業務知識を、5つの質問に変換します。

  1. 誰に伝える？
  2. 何を理解してほしい？
  3. 見たあと、何をしてほしい？
  4. 必ず入れる事実は？
  5. 間違えてはいけない情報は？
AI + TEMPLATE

構成・文章・レイアウトの初稿

PowerPointで編集可能
組織ルールを反映
公開前チェック付き

07　役割分担

日常制作は職員が。重要制作は専門家が。

すべてを内製化するのではなく、重要度に応じて役割を分けます。

日常制作

職員 + AI + テンプレート

定例資料 / イベント告知 / SNS画像

公開制作

職員 + 広報担当の確認

事業紹介 / 研究紹介 / 報告書

重要制作

デザイナー・専門家が主導

入試広報 / 大型事業 / ブランド

専門家をなくすのではなく、本当に専門家が必要な仕事へ集中させる仕組みです。

10　有償パイロット

まずは、1部局・1種類の資料だけ。

全学・全庁導入を前提にせず、小さな実案件で「本当に使えるか」を判断します。

広報資料セルフサービス化パイロット

4〜6週間　/　80万円〜

※対象範囲により個別見積り

  1. 現状を診断
  2. 試作品をつくる
  3. 職員が実案件で試す
  4. 結果を測り、改善する
11　効果測定と安全条件

成果は「おしゃれになった」ではなく、業務で測ります。

測る項目

初稿までの時間
修正の往復回数
初回承認率
セルフサービス率
ルール適合

安全に使うための前提

  • 公開・配布の最終承認は人が行う
  • 個人情報・機密情報は承認環境以外へ入力しない
  • AIから直接Web・SNSへ自動公開しない
  • 重要制作物は専門家が担当する
12　適合条件

この支援が向いている組織。

次のうち3つ以上あれば、小さなパイロットから始める価値があります。

□　似た資料を、毎月繰り返し作っている
□　専任デザイナーがいない、または依頼が集中
□　担当者によって資料の品質が大きく変わる
□　PowerPointや生成AIの運用が統一されていない
□　確認・修正・待ち時間が課題
□　全体導入の前に、1部局で成果を確かめたい
