01 / CURRENT STATE

毎回、誰かがゼロから作っている。

日常の広報物ほど外注しづらく、職員の時間を静かに奪います。

担当者ごとに見た目が変わる

引き継ぐたびに、品質がリセットされる。

修正指示が感覚的になる

「もう少し見やすく」が何度も往復する。

外注するほどではないが、時間がかかる

イベント告知や説明資料が後回しになる。

AIで作ってもそのまま出せない

組織のルール、正確性、確認工程が足りない。

制作時間の問題に見えて、実際は「判断が人の頭の中にしかない」ことが根本です。
02 / WHY TOOLS ARE NOT ENOUGH

AIやテンプレートを入れるだけでは、解決しません。

道具は増えました。けれど「この組織なら、どう見せるか」が共有されていません。

PowerPoint / Canva / 生成AI

便利な道具

組織の判断基準

ばらつく / 確認が必要

同じ見た目ではなく、同じ組織に見える。

ルールは守りながら、用途に応じて表情を変えます。画一化ではなく、判断してよい幅を設計します。

公式・明快

親しみ・参加促進

参加したくなる入口をつくる

先進・知的

固定する：ロゴ / 色 / 表記 / 必須情報 / 確認　｜　変化させる：写真 / 構成 / 余白 / 強弱 / トーン
04 / DESIGN HARNESS

組織の「これなら出してよい」を、職員とAIが使える仕組みにする。

単発のプロンプト集ではなく、次の資料にも使い回せる制作基盤をつくります。

01 集める

過去資料 / ガイド / 素材

02 ルールにする

見た目 / 表記 / 禁止事項

03 つくる

AI / テンプレート / 編集可能な初稿

04 確かめる

チェック / 確認 / 改善

AIでデザインを自動化するのではなく、制作判断を組織の仕組みに変えます。
05 / ROLE DESIGN

日常制作は職員が。重要制作は専門家が。

日常制作

職員 + AI + テンプレート

定例資料 / イベント告知 / SNS画像

公開制作

職員 + 広報担当の確認

事業紹介 / 研究紹介 / 報告書

重要制作

デザイナー・専門家が主導

入試広報 / 大型事業 / ブランド

09 / MEASUREMENT

「おしゃれになった」ではなく、業務で測る。

効果の見方

安全に使う前提

  • 最終承認は人が行う

  • AIから直接公開しない
